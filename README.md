# Lost at Checkout: Where Google Merchandise Store Sales Slip Away

Analysis of shopper journeys on the Google Merchandise Store during the 2020 holiday
season (Nov 2020 – Jan 2021): where shoppers drop off before buying, which marketing
channels bring in buyers, how Black Friday, Cyber Monday, and Christmas change behavior,
whether shoppers from wealthier countries buy more, and which products get abandoned in carts.

## Data
- GA4 e-commerce events: `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`
- World Bank WDI: `bigquery-public-data.world_bank_wdi`
- Google obfuscated this data, so findings are realistic patterns, not real store results.
